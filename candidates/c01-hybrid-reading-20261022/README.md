# C01 independent reading host candidate

This is a local correction to the isolated reading-interaction candidate published in commit `d4b1d8aef3f5bcdc8b9742c95937af13136c1c89`. This correction has not been published or opened in a real browser. Neither build is a new visual scene release.

## Local conclusion-excerpt correction

Real browser inspection of the published candidate exposed a content defect inherited from V4: ten non-Sinoseal studies showed a fixed-length opening metadata fragment under a judgment label. This patch replaces those fragments with each original report's own continuous, complete conclusion sentence or paragraph. The label explicitly says this is an excerpt, not the complete conclusion or a current recommendation. A visible line reference links to its existing source chapter. No excerpt is cut to a fixed character count or hidden with a line clamp.

Each excerpt is bound to the canonical study, full source SHA-256, byte count, exact UTF-8 source span and an existing heading anchor, after the usual whole-file integrity loader has succeeded. An identity or excerpt mismatch shows only an invitation to read the full conclusion. Original reports, research dates, Sinoseal's checked summary and charts, all navigation, and the reading host remain unchanged. This corrects presentation of existing research; it does not perform new investment research.

## What is connected

The overview keeps the eleven authorized fixed public snapshots, catalogue search/categories, selected research identity, and real links to the separate study, full reader, history and review pages. A native button opens one nonmodal, optional summary reading region. It is a sibling of the scene slot, not a projected model face. The complete original report remains on its own reader page; the summary does not replace it.

The host reuses the existing exact-byte/SHA-256 loader and checked chart/source derivation, with the conclusion-excerpt correction above. It clears the previous content before a new selection, rejects stale results and non-whitelisted identities, preserves native text nodes during state notifications, restores focus on close, and honors reduced motion. Text and its ancestor containers are not moved by a CSS perspective matrix. Only a separate decorative shell may animate. This avoids requiring long text to be coplanar with 3D; it is not a claim that the earlier device-specific glyph problem was conclusively reproduced or diagnosed.

Evidence charts and the two re-typeset public excerpts are bound only to the original Sinoseal snapshot. Other studies show their own text and honest missing-chart states. Annual and half-year values remain separate. Dates and reference prices belong to the historical report, not current quotes. Real source, version, archive and review distinctions remain intact.

## What is deliberately not connected

The new B-camera scene, mountain component, lighting/environment delivery and screen-space placement of short world labels are unfinished. No B render is used as a generic background: it contains Sinoseal-specific printed data. No substitute mountain is shown. The old three-board C01 renderer is not invoked by this overview either. The short native entries are currently semantic navigation controls, not falsely claimed world projections.

The explicit scene-port interface is only an integration boundary. A future real scene must announce actual availability and consume exact research ID plus complete SHA eligibility before its first draw and after every selection/loading/error transition. It must not use a matching company name or slug alone. Reading availability does not require WebGL. A reading interaction pass cannot establish geometry, material, occlusion, projection or scene quality.

Fine paper/page/fixture components and the separate curved-glass normal improvement remain preserved outside this public increment. They have not been silently merged into this page. The central mountain and complete new scene remain unresolved.

The study/history views retain their inherited V3-era presentation and controls. They are functional continuity, not the new B artwork. The inherited C01 model/projection assets remain inactive references in the package; their existence is not a rendered or accepted feature of this host.

## Identity and privacy

All five pages use the isolated `c01-hybrid-reading-20261022` route and storage namespace. The host does not read, migrate, upload or automatically open another candidate's review text. Review drafts remain explicit, local, research-and-SHA-bound records. No analytics, new external service, arbitrary source fetching, private research, credentials, original private ZIP, bank raw feeds or personal filesystem data is included.

The existing shared public runtime/research resources remain dependencies. This candidate does not edit them, the default site or earlier candidates. Material/font/component licenses do not transfer to research text. See [component notices](THIRD_PARTY_NOTICES.md).

## Verification boundary

The published predecessor was inspected in an assistant-cloud browser at 1180 × 757 CSS pixels. All eleven reports loaded with their expected identities; ordinary selection, copy and paste, open/close focus, nonmodal keyboard behavior, full-reader/back navigation, real archive distinction, source and review navigation, and invalid-parameter rejection were observed. That inspection discovered the conclusion defect above; it was not an overall pass. The new excerpt patch has local real-source and failure-boundary checks, not a post-patch browser check.

Narrow/mobile layouts, screen readers, reduced-motion-enabled browser behavior, HTTP-failure injection, performance, WebGL/GPU and same-camera B-scene rendering remain unverified. The available browser API did not expose viewport resizing; an ordinary zoom shortcut left the CSS viewport unchanged and is not counted as narrow-screen evidence. No GPU configuration was changed. Earlier V4 observations are not evidence for this patch.

No attempt is made to bypass the existing local-file/localhost/browser-evaluation restrictions. A later separately reviewed candidate publication or other supported preview entry is required before real DOM validation of these new files. No publication is authorized by this document.
