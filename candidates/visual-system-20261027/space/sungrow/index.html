阳光电源：现金质量与现价隐含假设

研究截点：2026年10月17日。价格基准：10月16日收盘76.86元。金额除特别说明均为人民币亿元。本轮在第一轮基础上补做产品毛利、营运资本、质保、股东现金及反向估值；不构成交易指令。

一、可用于决策的结论

单凭16.6倍扣非PE和9.1%的报表现金差额收益率，不能认定现价有充分安全余地。以本报告列明的现金参考值、增长和回报假设计算，76.86元仍需要更强的现金表现才能提供10%回报及额外余地。 公司并不缺现金；真正待验证的是本期现金释放、利润与再投资怎样形成未来股东现金。这里不宣称已经测得其长期可用现金或绝对合理价格。

  • AIDC进展已更新到10月：公司官网10月15日确认SST系统级认证，10月14日企业署名稿自述已商业交付和真实带载运行。技术落地可信度提高，但未披露销量、收入、利润和收款，不能当作经审计盈利，详见第五节。
  • 最新已核验总股本20.7321亿股，权益价格1593.47亿元；TTM归母109.85亿元、扣非96.09亿元，对应14.51/16.58倍。股数已补到9月30日的原始股份变动公告；采用总发行股数，未扣库存股，避免把将用于激励的股份视作永久注销；报价经多个二级渠道交叉核对，未证明其上游数据源独立，未取得交易所原始逐日行情。
  • TTM经营现金172.18亿元、扣购建资产支出27.21亿元后为144.97亿元，表面现金收益率9.10%。但现金流补充表中的三项营运资本变动累计贡献37.99亿元；把本期净释放设为零的对照值为106.99亿元；净释放能否持续尚未验证，不能直接定性为一次性，也不能把该对照值当成未来现金预测。它仍是合并、未完整处理利息/租赁/少数股东等的观察值。
  • 以扣非归母利润为起点，不加回经常性减值、质保成本和股份支付，加入非租赁折旧摊销、扣全部购建长期资产支出，得到约81.58亿元的混合口径现金参考值。它既不是已验证的正常化归母现金，也不是保证保守的下限；少数权益、维护/增长投入和未来营运资金均可能使真实股东现金高于或低于它。下面保留完整边界。
  • 仅在“所需回报10%、假定多余现金150亿元、第二至第五年现金增长5%、终端增长3%”这一组条件下，现价要求首年含金融收益现金约98.37亿元，并已剔除单列现金的重复利息计价。若终端增长改为2%或0%，同一要求升至108.55或127.15亿元。98.37不是通关门槛；81.58也不是固定正常化分母，两者都应随经营、风险、再投资及现金假设重算。

上修最重要的事实：储能收入重新增长时，毛利没有继续下降，且库存与预付采购确实转成收款。下修最重要的事实：毛利继续承压、海外回款恶化或美国业务收缩无法被其他地区补足。 提价、出货增长和AIDC订单必须经过利润及回款验证后，才能改变现金输入。后文约30%毛利率只是下降3个百分点的压力示例，不是降级红线。

在首年81.58亿元参考值、后续现金增长5%、终端增长3%并单列150亿元多余现金等假设下，现价可以覆盖约8%的所需回报，却尚不足以覆盖10%及额外安全余地；这不是对所有情景的绝对估值结论。降低终端增长或提高再投资需求会使结果转弱，反之亦然。报告不替用户指定所需回报率，也不把这些尚未校准的假设固化为买卖门槛。

二、利润来自哪里：逆变器的强项不能替储能背书

1. 产品毛利而非分部净利润

来源：2026中报第34—35页、2025中报第30—31页。按未四舍五入收入和成本重算。

储能少赚的20.94亿元毛利中，按“旧毛利率×收入变动＋新收入×毛利率变动”拆解，约9.37亿元来自收入下降，约11.57亿元来自毛利率下降。这里的收入效应混合销量、售价、地区、系统时长和确认节奏，不能称为纯销量效应。

逆变器等业务毛利率改善，抵消约8.64亿元收入下滑影响，毛利额仍减少1.86亿元。这显示该产品口径的毛利率具有韧性；与品牌、渠道及地区组合的解释相容，但本轮未独立分解各因素贡献，也不代表整个公司已经恢复增长。合并毛利额同比减少38.53亿元；储能解释约54%，两大产品之外的业务也解释约15.73亿元下降。

公司只披露产品收入/成本，未披露可直接对账的储能、纯逆变器独立净利润及现金流。销售、研发、管理费用合计49.75亿元，不能任意全部分配给某项业务，制造“储能净利率”。港交所会计师报告也将集团作为一个经营分部披露。公司交流称纯逆变器收入108亿元，不能与中报“逆变器等电力电子设备”123.88亿元混用。交流记录第3页、会计师报告I-34。

2. 海外占比上升，但海外收入本身下降

H1国内收入82.22亿元，同比-54.71%；海外226.90亿元，同比-10.59%。海外占比从58.30%升至73.40%，主要是国内下降更快，不能写成海外总收入高速增长。公司称欧洲、亚太较好，逆变器海外出货增加，但中东大项目的高基数抵消了部分增长。8月交流记录中“中东57亿元降到11亿元、下降91%”有明显算术不一致：按这两个约数计算约下降81%，本报告不用91%。

公司称储能发货25GWh、同比+28%，而储能收入下降13.18%。发货、收入确认和收到货款的时点并不相同，不把收入除以当期发货量当作可比系统ASP；更不把7.5GWh订单当成可立即分配的现金。逆变器66GW较76GW下降，也不能替代产品毛利和回款分析。来源：交流记录第2—5页。

新能源开发业务收入从83.98降至12.58亿元，公司交流称该业务净亏约3.8亿元。它既拖累利润，也占用项目存货；不能只假设收入恢复而不计恢复所需资金。重要非全资子公司阳光新能源H1净亏4.04亿元、经营现金-4.08亿元，较上年同期+5.96/+20.84亿元转弱；这一子公司口径和产品业务口径不同，不能把两个亏损相加。中报第184—185页。

具体风险比总额更重要：

  1. 预付款98.97%在一年以内，前五名占84.42%。这支持“集中采购/保供”的可能，但供应商名称及产品未完整披露，不能直接断言全部为电芯锁价，也不能宣布无回收风险。
  2. 存货增加约49亿元中，原材料增加23.15、库存商品增加10.62、合同履约成本增加14.34。公司解释为电芯、海外备货及开发项目投入。解释需要后续交付与现金验证，不等于客户已付清款项。
  3. 应收总额减少，但两年以上账龄从28.41升至33.86亿元；总坏账准备率由12.68%升至14.52%。这是“总量改善、尾部风险变差”同时存在，不能只报应收下降。
  4. 未到期质保金净额20.97亿元，组合坏账率从11.80%升至15.22%。港交所文件说明，通常保留合同额3%—10%、保留期2—5年，尾款以项目持续正常运行为条件。它既是信用风险，也是履约和质量风险。会计师报告I-67。
  5. 合同负债中货款预收111.41亿元，工程预收5.14亿元；重要的一年以上合同负债14.49亿元，其中单一客户2.70亿元因客户原因延迟发货。因此预收不全是当期新签订单，未来还需耗用材料、人工并承担质保。
  6. 票据提供资金缓冲，但要区分一般贸易票据和明确供应商融资。公司披露的供应商融资对应短借由15.57降至6.54亿元，不能因应付票据增加就说“供应链融资全部上升”。

四、售后与竞争：高毛利要承担多年义务

1. 质保费用已经实质影响经济性

中报质保预计负债56.83亿元，较年初55.69亿元仅增加1.14亿元。这个增量不是当期质保成本，也不是当期支付现金。

新补充的港交所会计师报告I-36、I-85披露，2025年质保费用24.47亿元；质保拨备计提/使用净额13.04亿元，另有汇兑增加0.30亿元。两者相减约11.43亿元，是推算的相关耗用差额，不能冒充单独披露的售后现金支付。存量56亿元准备对应的是多年产品责任，不是可以额外加给股东的现金资产。

业务章节第181—182页，分拆PDF第41—42页说明，逆变器和储能通常提供至少五年质保；渠道客户虽承担其下游服务，公司仍向渠道客户保修。2026H1没有取得按逆变器/储能拆分的质保新增计提、转回和实际付款，也没有可比批次故障率。结论应是“高利润确有售后负担，充足性仍需后续费用及现金证明”，不能凭准备余额判定利润虚增，也不能凭认证判定故障风险为零。

港股申请稿按IFRS编制，2025收入889.14亿元与A股年报891.84亿元存在列报差异。本报告只用该稿补足质保与合同条款，不将其收入、折旧和A股TTM混接。

2. 竞争反证和价格传导

公司8月交流明确表示长期电力储能毛利率趋向稳中下降，地区结构、时长和电芯成本都会影响季度毛利。其Q1/Q2毛利约数不能代替已披露半年32.43%的统一口径，也不能仅因Q2口头改善就把全年毛利恢复到40%。

可比竞争者阿特斯2026中报第20、196、245页披露储能系统业务收入56.59亿元、成本44.76亿元，重算毛利率20.90%；储能销量6.1GWh、同比+103.3%。产品成本、地区、保修与确认模式不同，20.90%不能直接当阳光的合理毛利率，但足以反驳“海外储能出货增长必然维持40%毛利”。阿特斯储能分部净利润6.78亿元是另一口径，不能与阳光未披露的分部净利直接比较；阿特斯全集团经营现金-8.94亿元也不能当其储能现金流。

有利证据是9月调价函，CNESA转载原件：覆盖产品总体拟提价5%—15%，其中电力/工商业储能系统原函列示为5%—10%；9月20日起只适用于新签/新订单，既有订单继续原价。其背景是金属和核心零部件成本上涨，所以不能把提价幅度直接加到毛利率。真正的上修证据是后续已确认收入的毛利、单位售后成本及收款同步改善。

五、海外和金融收益：不能用AIDC叙事覆盖可核算的风险

  1. H1财务费用中的汇兑损失5.87亿元，上年同期为收益3.28亿元，变动约9.15亿元。公司称套保收益约1.7亿元列于投资收益及公允价值变动。不可只加回汇兑损失而保留套保收益；本报告用扣非口径为起点，但扣非也不是“纯经营无汇率风险”利润。
  2. H1归母52.59、扣非42.75亿元，相差9.83亿元；金融资产处置/公允价值等非经常性项目税前约7.76亿元。它们不能自动年化为设备主业利润。中报第9—10、174—175页。
  3. 货币资金增长86.92亿元、现金等价物增长88.63亿元；同期理财本金赎回减购买净释放78.67亿元。现金变多很大程度是资产形态变化，而不是同额新增盈利。40.45亿元交易性金融资产中只有26.13亿元理财，其余主要为股票等，不能全当现金。
  4. 以已披露美元/欧元货币资金、应收、应付和借款粗算，净货币资产约171.5亿元人民币等值；5%人民币升值对应约8.6亿元税前静态敞口。这只是未抵销衍生品及未来经营自然对冲的压力量级，不是预测损失，也不是公司完整外汇风险表。中报第180页。
  5. 管理层8月表示美国业务会逐步收缩，暂不考虑美国本地化生产。应使用这条最新经营态度，而不是沿用较早申请稿中“关税影响有限”的表述。美国8月26日电力系统行政令原文第2、3、5节明确涉及并网逆变器和储能系统，并要求后续执行规则；是否禁止具体交易仍取决于法定判断及实施。不能将“69kV”理解为所有低压接入设备天然豁免，也不能宣布阳光所有美国销售已被禁止。交流记录把行政令编号写作14420，官方页为14421；本报告以官方原文为准。
  6. AIDC已有比8月交流更强的新证据，不能仍称“只有计划、尚未运行”。10月15日公司官网确认EnerNeo SST取得TÜV莱茵颁发的系统级欧美标准认证；10月14日署名阳光源智的企业稿转载称产品已商业交付，并在真实算力场景带载运行，且在英伟达MGX生态展区展示核心部件。这是正面的技术/商业化里程碑，提升未来落地可信度；但仍没有可对账的订单金额、确认收入、毛利及回款，不能把生态展示当作独家供应或规模利润已经实现。基准估值不追加未量化的新利润，待披露实际财务贡献后上修。此前8月披露数台交付及配储在手2GWh，属于较早状态，不覆盖10月进展。

六、究竟有多少现金可归股东

三层口径，不能互相替代

第一层，已发生的集团现金：TTM经营现金172.18减购建支出27.21等于144.97亿元。这是真实的报表差额；但合并经营现金包含少数股东经济权益，利息及租赁部分列在筹资，收购投资和股份回购也没有包含在购建支出中。TTM已披露借款现金利息约1.54亿元、租赁支付1.12亿元，单这两项还需区别处理，不能称144.97是可分红现金。

第二层，将三项营运资本净释放设为零的对照观察值：144.97−37.99=106.99亿元。它有助于看清现金质量，但仍含减值和股份支付等非现金调节、税款时间差、少数股东，并未验证持续再投资需求。该值不是估值模型的首年股东现金，也不代表本期37.99亿元释放以后必然消失。

第三层，估值参考用的混合口径现金代理，尚非已验证正常化现金：

扣非归母96.09＋非租赁折旧摊销12.70−全部购建长期资产支出27.21＝81.58亿元。

处理原则：

  • 不把坏账、存货跌价和质保成本加回来；这些在持续经营中代表真实经济损失或产品责任。
  • 不加回股份支付，避免假定激励是免费资本。也不把用于员工计划的回购算为等额永久注销回报。
  • 不加回使用权折旧，作为持续租赁成本代理；没有再次把完整租赁付款重复扣减。实际租赁现金与会计成本存在小幅时差。
  • 利息成本已在净利润中扣除，不再重复扣融资现金利息；正常现金利息收入保留。单列“多余现金”估值时再减去相应收入。
  • 全额扣购建支出，没有未经验证就声称其中大部分可省。缺少维护/增长资本开支拆分，若未来证明确有可减少的扩张支出，现金代理可上修。
  • 归母利润与合并折旧/资本开支混接仍有少数股东边界误差；它是混合口径筛选参考值，不是精确法律可分配额，也不能保证偏保守。主要设备子公司多为全资，但非全资新能源和其他子公司仍不可忽略。集团不披露完整逐实体归母现金桥，不能据此制造精确归母FCF。
  • 该式尚未扣未来增长需要的额外营运资金。模型中的现金增长必须是已经支付新增营运资本和增长投入之后的增长，不能只填利润增长率。

母公司单体TTM经营现金85.48亿元、购建支出8.66亿元、差额76.83亿元，可作为另一角度的核对，但母子公司结算和股利会影响它，不能简单加到集团现金之上。H1母公司这一差额13.62亿元，略低于当期支付现金分红14.20亿元；同时母公司期末现金262.14亿元，不能据此推导资金短缺。中报第96、179页及年报第115页。

少数股东实付股利的历史表格还存在待核差异：2025中报及2026中报比较数为0.7198亿元，而2025年报全年为0.6087亿元。没有据此构造负的下半年少数股东股利；这也限制了精确TTM归母现金桥。本报告的条件判断不依赖填平这项差异。

可用现金余额与实际分配

6月底现金等价物308.61＋理财26.13−广义融资负债86.67≈248.06亿元。融资负债口径包含租赁和长期应付款，后者含少数投资者回售义务，避免只扣银行借款虚增净现金。但这248.06亿元仍是账面净流动金融资源上限，不能直接认作全部可分红：需满足运营、票据和保修等义务，且是6月底快照，后续已有分红与回购。

2026年5月实际分红14.20亿元，9月再分13.17亿元；两次每股合计1.33元，对76.86元为1.73%，是已宣告/实施分配，不是未来固定股息率。9月21日已除息，不能再把0.64元加回10月16日现价价值。2026回购计划截至9月末支出3.25亿元、买入304.76万股，用途为员工持股/激励，不是注销。9月分红公告、10月回购进度。

七、用现价反推现金，不使用任意PE门槛

模型把第一年现金F1独立指定；第二至第五年按g增长，主表第六年以后按3%永续增长，另加0%和2%终端增长敏感性；按8%、10%、12%股东所需回报折现。这是敏感性分析，不声称已准确测得公司股权资本成本。终值占比高，表格不能当成精确目标价。

主模型不额外加净现金，保留现金利息收益，避免“双算”。另列150亿元多余现金敏感性：远低于248.06亿元账面上限，但仍是假设而不是已证明可分配；为防双算，首年现金先扣150×2.5%=3.75亿元假定税后收益。2.5%仅作显式假设，非公司实际收益率预测。

八、哪些事实会改变判断

上修所需的最短证据链

  1. 下一份季报若披露产品数据，储能毛利稳定或恢复，同时收入/确认量增长；如只披露集团毛利，不能据此确认储能恢复。
  2. 半年新增的原材料、库存商品和预付款兑现成发货、验收与现金；观察库存/预付合计是否回落、经营现金是否仍靠应付票据扩张，及两年以上应收是否停止增加。
  3. 用新增财报重建归母现金、资本开支及增长所需营运资金。仅在10%所需回报、150亿元假定多余现金、随后四年现金增长5%、终端增长3%的情景中，98.37亿元才是现价反推要求；它不是通关阈值。经营、风险或再投资条件变化时应整体重算，而不是只检查是否超过98—100亿元。
  4. 美国收入收缩由其他地区真实利润和现金补上；AIDC已见真实带载和认证进展，下一步需量化正式收入、毛利和付款后才追加基准利润，而非仅凭认证、生态展示和框架订单。

最有力的下修信号

  • 储能收入恢复但毛利继续下行，且质保/运费没有改善，需要判断竞争、地区结构和成本传导，并下调相应现金假设；不设置30%这一硬红线。
  • 库存和预付继续上升、应付融资同步扩张，现金利润无法通过回收兑现。
  • 长账龄应收、质保尾款减值继续增加；产品批次售后费用上升，原有准备不足。
  • 美国交易、客户退货/索赔或海外准入产生可量化损失，同时AIDC尚无现金补充。

缺口按影响排序：①2026H2储能地区/时长结构与毛利；②库存预付交付和回款；③储能质保费用及实际付款；④逐实体股东现金与维护资本开支。已优先补齐能改变当前判断的现金补充表、港交所质保披露、最新股本及价格传导原件。在本报告明确列出的10%回报及现金增长等情景下，现价尚未显示额外安全余地；这项条件判断可以使用，但不能外推为已证明的绝对高估，也不能把81.58亿元代理或未来现金结果写成已证实。
