The PDF links are external registered sources and require network access. Those references are not bundled, and failed external reads must not be represented as successful original-document viewing.

No claim of browser execution is made by the source checks or offline geometry frames. This package contains no server-side data, user financial accounts, credentials, analytics or automatic external writes.
