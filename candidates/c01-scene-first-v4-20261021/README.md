# C01 · 场景先行研究总览候选

这是独立候选，不替换原工作台或 V1 / V2 / V3。新建的是 C01 总览；关系、历史、完整阅读和独立复盘沿用 V3 功能并使用本候选自己的路径和存储前缀。

## 此次改变

- 场景有固定的米制尺寸、真实承载关系和主相机。桌面宽 5.12 米、高 0.76 米，前景纸本和工具、中景研究装置、三个信息载体、远景建筑开口构成完整场景。几何不读取 DOM 外框反向生成。
- 左侧为深绿证据翼，中央为瓷质研究面，右侧为暖灰记录翼。三个内容面的尺寸、位置和朝向见 [scene-layout.json](assets/scene-layout.json)。中央为 1.56 × 1.14 米，左右各 1.34 × 1.64 米。中央阅读画布为 456 × 333 CSS px，左右各 374 × 458 CSS px。
- 正文为可选择的原生 DOM。四角由同一 Three 相机和固定内容平面投影，再计算完整平面变换；不是只移动中心和等比缩放。长文仍在原生 reader 中阅读。
- 相机限制为水平 ±3°、俯仰 ±1.5°、缩放 98–108%。不自动旋转、不拦截普通页面滚动，键盘控制只在指定按钮聚焦时生效；保留 Ctrl/Cmd/Alt 浏览器快捷键。
- 窄窗口、内容溢出、不可容纳的投影和 WebGL 失败有明确阅读回退。可用模型的越界视角保留“归位恢复”；真正的图形初始化、上下文或渲染失败不会被控件误复活。

## 数据与范围

研究、原文、来源和历史沿用现有 11 份公开固定快照。每份原稿必须通过 SHA-256、字节数、标题核验后才显示。中密控股的修复收入图表和两个节选缩略图来自该原稿；年度与半年分开，节选明确为重排，不是公告原页。不为其他研究套用图表，不补造置信度、行情、关联或历史版本。

只有一份原稿就只显示单一快照。宏华数科保留当前稿与撤回论证的修订前归档，不把两个口径混为有效版本。复盘存储按候选、研究 ID 和 SHA 隔离，不读取正式工作台或 V3 的本地复盘。复制研究衔接文字不等于自动填入、发送或保存到 ChatGPT。

## 合成限制

WebGL 几何与 DOM 没有任意逐像素深度融合。本候选通过固定布局和有限镜头避开信息面前方的交叉几何；四角矩阵和主要前景物体的数值检查不能代替真实 GPU 对重叠、透明排序、文字清晰度和点击命中的验收。

原创建模的空心玻璃器皿位于前景，使用 glTF transmission / IOR / volume 参数，不置于文字面前。石材颜色乘子已写入 GLB 的标准 PBR 字段。离线渲染和浏览器使用不同渲染器，不能宣称画面一致。PBR、PMREM、阴影与色调映射是实现配置，不是质量通过的证明。
