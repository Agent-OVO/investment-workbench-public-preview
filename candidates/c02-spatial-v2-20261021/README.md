## 完整主画面

中央为研究书页，左右为各自共用后支架的双层证据翼，不再是五块同质立牌。五区保留同一份已公开、校验过 SHA-256 的中密控股研究：主问题、支持线索、选定产品毛利变化、修复收入及口径、后续核验问题。全文、原文所在章节、来源与下载仍是独立页面，不用小弹窗替代研究。

每个载体由实际厚度、倒角玻璃、金属边框、背面连接件和完整阅读面组成。阅读面在世界空间保留不同位置和深度，并与相机一起定向；DOM 文字与该物理面四角一致。默认文字无 CSS transform，不将字号缩小塞入模型，也不再按行添加白底纸条。文字及图表数字可选择；图表 SVG 只绘制条形。

## 操作与诊断

- 在空白舞台或独立手柄拖动，滚轮 / ± 适度缩放。Yaw ±4°、pitch ±2°、zoom 0.94–1.06；没有自动旋转或惯性。
- 五区的“聚焦”按钮保留其他四区与全文入口。Home、Escape、重置和“返回总览”可恢复。
- 方向键可调整视角；文字选取和链接不触发拖动。紧凑阅读降级时，画布保留页面竖滑与捏合缩放，只有手柄接管拖动。
- “说明与设置”中的无透视、仿射、matrix3d 三种文字诊断使用同一物理阅读面。它们是用于定位字形问题的可复核模式，不是“已修好实机破字”的声明。
- 手动复制诊断只包括候选版本、视角、文字模式、舞台尺寸、DPR 与未验收标记，不包括账号、文件路径或私有研究。

正交相机对照未达到五面入框要求，已从本候选移除；保留透视相机与三种同面文字合成诊断，不作为已交付功能。

## 检验边界

舞台机位按可用宽高做 width-fit，不因常见 16:10 桌面直接放弃空间。2048×1096、1920×1080、1672×941、1366×768、1280×800、1440×900、1672×1061 的允许视角、缩放和五区选择组合已做 CPU 几何检查。它只证明投影面入框、无互叠及同面映射，不证明最终浏览器文字布局、材质、反射或观感。

紧凑模式的主判断为 13–19 CSS px、标题 19–26 px；数值、期间、来源和关键口径至少 12 px，默认不做 CSS 缩放。离线 Noto CJK 字体预算仍不能代替用户字体和浏览器实测。

手机、浏览器文字放大或空间确实不足时保留完整阅读流；这不计作完整空间验收。仍待真实设备核验：字形完整性、完整五区实际排版、触屏、选字与链接、支架与材质观感、反射/阴影、GPU 帧时间。未改变云端浏览器或 GPU 设置，也未绕过拒绝访问。

候选仅复用已有公开依赖，不改原入口，可独立撤回。公开审阅不等于正式采用；后续是否替换现有入口，仍待用户视觉验收与确认。
