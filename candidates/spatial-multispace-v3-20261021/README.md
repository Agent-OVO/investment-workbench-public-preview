# 多空间 V3 · 独立候选

这是一份独立实施候选，不替换原工作台、V1 或 V2。入口 `?report=sinoseal` 展示已公开的中密控股研究。未带研究参数的总览/关系入口会明确初始选择中密控股；未知、空值或重复研究参数不会自动换成另一研究。阅读、时间和复盘页面要求明确研究身份。

## 四个入口，各有任务

- 总览：以选中研究为核心，左侧证据、右侧研究浏览/真实版本、前景下一次核验。不是全市场行情仪表盘。下方目录为 11 份既有公开研究样本，分类仅为可清除的浏览辅助，不限制研究对象、方法或行业。
- 关系：中密控股的一份原稿被组织为支持、数据、反证和追问四个方向。连线是同一文档的阅读关系，不是跨公司因果或自动生成的引用。其他研究未绑定关系时显示明确空态，不移植中密图表。
- 时间：真实保存内容形成版本队列。宏华数科展示当前修订稿与相关论证已撤回的旧稿，其余没有前版原件的研究只显示一份。大小表示当前选择，不表示版本更优。航空/白云为同专题独立补充，不是全文版本替换。
- 阅读：完整可复制原文、章节、来源、图像、原表和版本导航。中密两个原表增加明确标注的衍生图表，原文没有被删减或改写。提供“生成衔接文字 → 复制 → 打开 ChatGPT”的手动继续研究入口，仅使用公开研究身份与所选问题，不默认附带复盘笔记，不自动填入、发送或回写研究。阅读使用宽主列而非在3D卡片内滚长文；C04 的进一步三维承载美术尚未完成。

## 排版和模型的关系

展示标题使用自托管、改名的 Noto Serif CJK SC 子集；正文使用 Noto Sans CJK SC 子集。字体和许可随候选提供。普通正文保留网页文本，可选择、检索与复制。没有用生图文字代替正文。

总览、关系和时间使用各自的 Three.js 几何承载构图。承载框尺寸跟随实际 DOM 阅读区域，正文是无透视变形的正向阅读层；外层玻璃/框使用独立世界角度，支撑和桌台保留三维厚度与高差。正向 DOM 并非与倾斜玻璃严格共面的透视字面，不能据此宣称已完成模型融合或消除屏幕朝向感。不再给整个承载面叠加第二层不透明白板或绿色底板。图表均由已核验原稿的明确数据重新排绘；图像节选标明“原稿重排，非公告原页”。山景只作已有项目艺术环境，不是研究证据。

## 有限空间互动

总览、关系和时间在 WebGL 可用时提供明确操作条：仅在“拖动此处”手柄拖动或滚轮缩放，方向键微调、加减缩放，Home / Escape 或“归位”返回全貌；聚焦按钮对应当前真实载体。相机有界偏航 ±4°、俯仰 ±2°、缩放 94–106%，不是自由环绕。固定世界模型和稳定锚点从同一个真实透视相机投影，正文层按投影中心与深度同步位移、缩放，仍保持正向阅读。操控帧不重建几何，不从已变换的 DOM 反推世界位置。

正文选择、链接、表单和页面滚动不被拖拽接管。没有惯性、自动旋转或过渡动画，系统减少动态偏好下亦然；失焦、取消指针或释放即终止拖动。相机数值与聚焦 ID 按本候选、页面、研究及原稿 SHA 独立保存在当前浏览器会话中；从正文正常返回恢复该身份的视角。切换到未保存视角的研究/版本时归位，不跨身份继承聚焦；显式“归位”覆盖当前身份的视角。浏览器禁用会话存储时仍可操作，但无法跨页面恢复。真实内容、字体和视口尺寸变化才重新测量承载；小屏或 WebGL 失败时控件停用并明确保留阅读模式，不宣称已有空间互动。

## 数据与状态

沿用已公开的 11 个研究 ID、原文 SHA-256、日期、完整原稿和共享来源入口。先核验原稿字节身份，之后才展示图表与节选。这不代表重新核验历史研究事实，也不表示历史价格是当前行情。

复盘只读写本候选前缀 `spatial-multispace-v3-20261021:review:v1:`。不读取、迁移或覆盖原工作台/V1/V2 的复盘。阅读位置仅在当前浏览器会话中按本候选研究 ID 与原稿哈希隔离保存，不包含研究正文或复盘内容。外部来源在新标签打开。

银行研究仍只提供既有公开财报分析、说明与六份财报来源索引，不分发旧 ZIP、行情 CSV、历史估值序列、旧复算脚本或 PDF 原件。

本批先进行语法、依赖、公开原稿哈希、状态/存储隔离及 DOM 夹具验证。夹具不是浏览器。WebGL 可用时创建真实几何；不可用时明确显示排版阅读模式。小屏采用完整阅读流，不把回退截图当作手机 3D 验收。

真实浏览器布局、字体加载、WebGL 美术、透明排序、手机和 GPU 性能尚未通过视觉验收。代码尺寸、投影计算及字体 cmap 检查均不等于实际截图验收。是否替换原站仍须另行体验批准。
