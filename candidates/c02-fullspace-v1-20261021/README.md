# C02 complete-space V1 isolated candidate

This is a public review candidate, not a replacement for preview.2 and not a claim of completed 3D visual or GPU acceptance.

Open [the candidate](./?visual=c02-complete-v1), [matching orthographic camera](./?visual=c02-complete-v1&camera=orthographic), or [unchanged preview.2](../../workbench-review/models/c02/?visual=c02-light-study&preview=0.1.0-preview.2).

The same Three.js r149 scene contains the retained environment and five transparent carriers. Five reading views bind to the already public, hash-checked Sinoseal research snapshot, not invented research. Source and chart periods remain 2026-10-17 UTC / 2026-10-16 / 2026-06-30 as labelled. No new market data is introduced.

The candidate reuses public shared dependencies from repository baseline 3d4fd3eba1256cb0801ea006ce3892eb0ad2f3f3. All existing repository paths are unchanged. Its dependency fingerprints and new-file hashes are in CANDIDATE_MANIFEST.json; release scope and validation limits are in RELEASE.json.

On narrow viewports, failed 3D startup, or unreadable projection, the verified research remains in ordinary reading flow. This fallback is not a visual substitute for the intended complete 3D composition. Glass, reflection, occlusion and fixed-view composition still require a supported real WebGL browser.
